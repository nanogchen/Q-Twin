# Q-Twin
A Digital Twin for Molecular Scattering

## How to use

### Local mode
Main packages used are included in the requirements.txt file and can be installed by one of the following ways:
> (myenv) conda install --file requirements.txt
> 
> (myenv) pip install -r requirements.txt

Switch into the python environment with above packages, then:
> streamlit run app.py

### GUI version
Use the "install-free" version deployed in the cloud
